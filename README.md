# NEXUS STUDENT COMMAND CENTER

Build a working AI Student Command Center web app based on the supplied blueprint. Enable Lovable Cloud first for authentication, persistent student/task/material data, file uploads, and AI features. Create a polished responsive dashboard with pages for Dashboard, Tasks, Study, Materials, Quizzes, Flashcards, Projects, and Internships. Implement signup/login, student profile fields, CRUD task management with deadlines/priorities/status, AI task breakdown from natural-language prompts, and materials upload/listing. Use a focused student productivity experience; make remaining modules useful starter experiences rather than empty pages.
